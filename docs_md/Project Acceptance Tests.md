Project Acceptance Tests

Group 47

## Test A – Language Selection

A setting that allows the user to switch the displayed language of the app. A functioning 	language select should achieve the following criteria:

It changes all text (excluding user-inputted text such as names) to the desired language 	with minimal change in semantics. This means no placeholder text and no text with a 	missing counterpart.

It is easily accessible. This means that it preferably takes fewer than 5 actions to go from any screen to changing the language.

It is comprehensible. Text for both languages are easily understood.

## Test B – Child Registration

The main process to register a new child into the system. This process should be the first 	visible thing when opening the app for the first time.

Able to set and store the name, date of birth, and sex of the child, as well as other important information. Information should be retained and secure when closing and opening the app.

Correctly calculate and display age and vaccine schedule using the phone’s built in date and time.

Able to edit or delete profiles.

## Test C – Vaccine Reminder System

Processes that remind the user of upcoming or catch-up vaccinations. In order to facilitate 	these reminders, the app should be able to send a push notification with the following 	criteria:

It is sent even when the app is closed.

It is sent at the scheduled date and time.

It contains only the relevant information in clear wording.

It is sent in the selected language.

## Test D – Immunisation Information

A section within the app that provides information regarding immunisation. It must:

Be available in all selectable languages (as previously mentioned in Test A)

Be easy to navigate. This means finding the section on the app, searching for a specific topic, and exiting the section should all preferably take fewer than 5 actions each.

Be available offline.
